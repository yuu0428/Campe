# Campe

## PowerPointのノートを貼り付け用テキストに変換

発表者ノートにある原稿と秒数を取り出します。スライド本文から原稿を生成したり、原稿を書き直したりはしません。元のPowerPointは変更しません。Python 3.8以降を使用します。

```sh
python3 scripts/pptx_to_campe.py '/path/to/presentation.pptx' -o '/path/to/原稿.campe.txt'
```

出力されたテキストを全文コピーし、Campeの「インポート」に貼り付けて「取り込む」を押してください。スライドの順序、ページ内の空行、各ページの秒数が取り込まれます。

```text
【Campe原稿 v1】

【スライド 1｜60秒】
1ページ目で話す原稿。

同じページの次の段落。

【スライド 2｜23秒】
2ページ目で話す原稿。
```

この例では2ページ目に「このページ：23秒」「開始から1分23秒までに読み切る」と表示します。時間にはノートに記載された切り替えの間も含みます。通常の文章だけを貼り付けた場合は、従来どおり空行ごとにページを分割します。

## ノートの対応形式

各ノートの冒頭に、次のいずれかを記載します。原稿の途中に出てくる秒数は、そのまま原稿として残します。

- `このスライド：23秒`（`このページ`、`所要時間`、`読む時間`、`読み上げ時間`、`持ち時間`も対応）
- `0分24秒〜0分43秒`、`0:24〜0:43`
- `0分43秒までに次のスライドへ。`、`1分23秒までに読み切る。`
- 範囲の後ろにある `（このスライド：約19秒・切り替えの間を含む）`
- 冒頭の `【進行目安｜発表開始を0分00秒として】`

PowerPoint内の表示順とノートへの参照を使います。ノート番号やファイル名の順には依存しません。ノートが欠けている、形式を解釈できない、開始・終了・所要時間が矛盾する場合は、該当ページを表示し、出力しません。前ページから時間が空く場合は、その間を前後のページの所要時間に含めてノートを調整してください。

未対応の書式をAIで変換する場合も、既存の原稿と秒数の抽出・形式変換だけを行い、不明な時間を推測しないでください。出力は上記のCampe原稿形式に統一してください。
